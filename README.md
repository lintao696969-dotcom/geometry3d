# 几何3D

这是一个桌面端 3D 画图工具，基于 Electron + React + Vite + Three.js 构建。

## 技术栈

- Electron
- React
- TypeScript
- Vite
- Three.js

## 启动方式

1. 安装依赖：
   npm install

2. 启动开发模式：
   npm run dev

3. 构建生产版本：
   npm run build

## 说明

当前版本已经包含：
- 3D 场景窗口
- 基础旋转立方体演示
- 左侧工具栏
- 顶部菜单
- 登录入口

后续可以继续扩展：
- 3D 物体创建
- 旋转、缩放、平移
- 对象属性面板
- 用户注册/登录
- 文件保存与导出
